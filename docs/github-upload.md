# Uploading to GitHub

## Repository details

**Repository name:** `brainboard-quiz-game`

**Description:** A touchscreen quiz game for the RA6M3 HMI board, built with C, RT-Thread, and LVGL, featuring five questions, score tracking, and a game timer.

**Suggested topics:** `embedded-systems`, `c`, `rt-thread`, `lvgl`, `ra6m3`, `hmi`, `quiz-game`, `squareline-studio`

## Upload steps

1. Extract the ZIP and open the `brainboard-quiz-game` folder.
2. Create a GitHub repository using the name and description above. Leave GitHub's README, `.gitignore`, and license initialization options unchecked so the repository starts empty.
3. Upload the contents of `brainboard-quiz-game`, including `.gitignore` and `.gitattributes`. Place `README.md`, `SConscript`, `CMakeLists.txt`, and `src/` directly at the repository root.
4. Use this initial commit message: `chore: organize BrainBoard project and add documentation`.
5. Add the suggested topics in the repository's About settings. You can also use the Hackster project URL as its website link.

Upload the extracted files so GitHub can display the README and browse the source code.
